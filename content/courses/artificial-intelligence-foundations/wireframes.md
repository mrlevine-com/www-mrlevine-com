## Lesson Overview
### What is a wireframe?
{{% define "Wireframe" %}}

Like a blueprint, a wireframe plans where things go before anyone builds. Draw it with simple shapes:

| Shape | Shows |
|-------|-------|
| Navigation bar | How users move between pages |
| Box with an X | Where an image, video, or icon will go |
| Lines | Where text will go |
| Labeled boxes | Buttons and inputs users interact with |

### What is abstraction?
{{% define "Abstraction" %}}

When you leave colors and details out of a wireframe, you keep only what matters for structure.

### How do you give feedback on a wireframe?
Start with "I like...," "I wonder...," or "I wish...," and focus on whether a user could find their way from page to page, like "I wonder how a user gets from this page to the next."
