### Encrypt a Binary Number
- **Algorithm**: Write the key below the binary number. Then, going bit by bit, write a 1 if the two bits above it are the same, or a 0 if they are different.
- **Key**: 01011010

{{< collapse summary="Click here to see an example." >}}

- Number: `1010`
- Key: `1100`
- Encrypted: `1001`

{{</ collapse >}}
