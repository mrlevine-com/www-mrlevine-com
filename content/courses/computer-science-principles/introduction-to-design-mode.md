## Lesson Overview
### How do you build the user interface of an app?
{{< collapse summary="Click here to reveal the answer." >}}

Design Mode lets you build the screen of an app by dragging elements onto it, such as buttons, images, and text. Once you place an element, you can change its properties to customize how it looks and behaves. Different elements have different properties: for example, a text element has choices like text alignment and font, while an image element has choices like which picture to display.

Every element also has an ID, a name you give it so you can keep track of what it does. Choosing a meaningful ID, such as `submitButton` instead of `button1`, makes it much easier to work with your app later.

You can also choose a theme for your app's screen, which controls its overall look. No matter which theme you choose, you can still override the design of any individual element.
